# SiapSatu Domain Strategy

Checked: 2026-10-14

## Recommendation

- **Primary:** `siapsatu.my`
- **Defensive redirect:** `siapsatu.com` if the registrar checkout confirms it is available at a normal price
- **Internal/staging only:** `siapsatu.syahmiaof.my`

## Why

`siapsatu.my` is short, memorable, and immediately signals a Malaysian learning brand. It keeps the product independent from the founder's personal domain while leaving room for more modules and a community later.

`siapsatu.com` is useful for future expansion and typo/brand protection. If it is premium-priced, do not overpay at launch; use `siapsatu.my` as canonical and redirect the `.com` only if the economics make sense.

`siapsatu.syahmiaof.my` is technically convenient because it can be created as a DNS subdomain, but it is longer and makes the product feel like a project inside a personal site. Keep it for preview, admin, or staging environments.
